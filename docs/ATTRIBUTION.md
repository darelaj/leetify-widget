# Leetify attribution assets

The widget bundles unmodified small PNG badges from the folder linked by the [official developer guidelines](https://leetify.com/blog/leetify-api-developer-guidelines/).

- [Official badge folder](https://drive.google.com/drive/folders/1FkJf6iseD3AOFtnOhyGkRp1fea_gKima)
- `leetify_badge_black.png`: [Leetify Badge Black Small.png](https://drive.google.com/file/d/17GYce9skKrAPoEp7WMyq641BQkTiAWwH/view), 7,291 bytes, used on light backgrounds.
- `leetify_badge_white.png`: [Leetify Badge White Small.png](https://drive.google.com/file/d/1vN3f-vv2KPH20nkeVuJreXp_3sYRTTLZ/view), 6,423 bytes, used on dark backgrounds.

Downloaded 18 November 2026. Files retain their original pixels and proportions; Android resource names differ from the original filenames. The badge links to Leetify's landing page, and the profile action uses the prescribed View on Leetify label. This independent app is not affiliated with or endorsed by Leetify. Attribution does not resolve the separate render-retention clarification required before release.
